# Kotlin TODO CLI

コマンドラインで動作するTODOリスト管理ツール

## 📝 概要

Kotlinの基礎学習を目的とした、シンプルで実用的なタスク管理CLIアプリケーションです。
対話型のメニューシステムで直感的に操作でき、タスクデータはJSON形式でファイルに永続化されます。

## ✨ 機能

### 基本機能
- ✅ タスクの追加（タイトル、優先度、期限）
- ✅ タスク一覧の表示
- ✅ タスクの完了/未完了切り替え
- ✅ タスクの削除
- ✅ タスクの編集

### 検索・フィルタリング
- ✅ キーワード検索
- ✅ ステータスでフィルタ（完了/未完了）
- ✅ 優先度でフィルタ
- ✅ 期限切れタスクの抽出

### 並び替え
- ✅ 優先度順（高→中→低）
- ✅ 期限順（近い順）
- ✅ 作成日順（新しい順/古い順）

### データ管理
- ✅ 自動保存（タスク追加・変更・削除時）
- ✅ 起動時の自動読み込み
- ✅ 手動保存・再読み込み
- ✅ バックアップ作成

### 統計・分析
- ✅ タスク総数、完了数、未完了数
- ✅ 完了率の表示
- ✅ 期限切れタスク数
- ✅ 期限が近いタスクの警告（3日以内）

### その他
- ✅ 完了済みタスクの一括削除
- ✅ UTF-8対応（日本語表示可能）
- ✅ 柔軟な日付入力形式（yyyy-MM-dd、yyyy/MM/dd等）

## 🛠 技術スタック

- **言語**: Kotlin 1.9+
- **ビルドツール**: Gradle
- **JSON処理**: kotlinx.serialization
- **開発環境**: Android Studio
- **JDK**: 17+

## 🚀 実行方法

### 1. プロジェクトを開く
```bash
git clone https://github.com/YOUR_USERNAME/kotlin-todo-cli.git
cd kotlin-todo-cli
```

### 2. Android Studioで開く
1. Android Studioを起動
2. 「Open」から `kotlin-todo-cli` フォルダを選択
3. Gradle Syncが完了するのを待つ

### 3. 実行
1. `app/src/main/java/com/example/todocli/Main.kt` を開く
2. 緑の▶️アイコンをクリック、または右クリック → **Run 'MainKt'**
3. 下部のRunタブに対話型メニューが表示されます

## 📖 使い方

### メニュー画面
```
==========================================
1. タスクを追加
2. タスク一覧を表示
3. タスクの完了/未完了を切り替え
4. タスクを削除
5. タスクを検索
6. タスクをフィルタリング
7. 統計情報を表示
8. タスクを編集
9. タスクを並び替えて表示
10. 完了済みタスクを一括削除
11. バックアップを作成
12. 手動保存
13. ファイルから再読み込み
0. 終了
==========================================
```

### タスクの追加例
```
選択してください: 1
--- タスクの追加 ---
タスク名: Kotlinを学ぶ
優先度を選択 (1:高, 2:中, 3:低) [デフォルト: 2]: 1
期限 (yyyy-MM-dd または yyyy/MM/dd形式、なしの場合は空Enter): 2025-11-20
タスクを追加しました: Kotlinを学ぶ (ID: 1)
```

### 日付入力フォーマット
以下のすべての形式に対応：
- `2025-11-15` （ハイフン区切り）
- `2025/11/15` （スラッシュ区切り）
- `2025-1-5` （0埋めなし）
- `2025/1/5` （0埋めなし）
- `20251115` （区切りなし）
