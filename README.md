# Kotlin TODO CLI

コマンドラインで動作するTODOリスト管理ツール

## 概要
Kotlinの基礎学習を目的とした、シンプルなタスク管理CLIアプリケーション

## 機能
- [ ] タスクの追加
- [ ] タスク一覧の表示
- [ ] タスクの完了/未完了切り替え
- [ ] タスクの削除
- [ ] ファイルへの保存・読み込み
- [ ] タスクの検索
- [ ] 優先度設定
- [ ] 期限設定

## 技術スタック
- Kotlin 1.9+
- kotlinx.serialization
- Gradle
- Android Studio

## 開発環境
- Android Studio
- JDK 17+

## 実行方法
1. Android Studioでプロジェクトを開く
2. `Main.kt` を開く
3. 緑の▶️アイコンをクリック、または右クリック → Run 'MainKt'

## 学習目標
- Kotlinの基本文法習得
- データクラス、sealed class、enum
- コレクション操作
- ファイルI/O
- null安全性
- 高階関数とラムダ式
